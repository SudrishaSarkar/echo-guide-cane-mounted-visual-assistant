# models/

Model weights are downloaded here, not committed to git (`.gitignore`
excludes `*.pt` and `*.task`).

- `yolo11n.pt` — downloaded automatically on first run of the object
  detector or `yolo predict ...`.
- `hand_landmarker.task` — download the current MediaPipe Hand Landmarker
  task bundle from the MediaPipe docs and save it here.
