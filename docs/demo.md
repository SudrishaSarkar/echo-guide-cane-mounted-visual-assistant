# Demo script and test log (skeleton)

## Demo script

1. Connect hardware, start backend (`uvicorn`) and frontend (`npm run dev`).
2. Approach with an object -> directional obstacle warning (left/centre/right audio).
3. Stop, move joystick -> camera visibly pans/tilts.
4. Tap touch sensor -> short spoken scene description.
5. Long-press touch -> SOS event on caregiver dashboard; cancel within window.
